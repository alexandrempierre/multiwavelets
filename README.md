# Implementação de Multiwavelets de Alpert

## Resumo

Comparação do método de multiwavelets de Alpert e Trapézio (clássico e adaptativo) para problemas específicos.

Multiwavelets de Alpert são um método de solução numérica de operadores lineares num espaço de funções com um número finito de singularidades. Um método complexo e com vários passos [devido à análise multirresolução?]. A corretude da implementação de cada passo das Multiwavelets de Alpert para Operadores de Fredholm do Segundo Tipo é garantida por testes unitários.

A comparação entre os métodos é feita usando os números de condicionamento dos métodos e comparação de erro absoluto em exemplos específicos retirados da tese do Alpert.
